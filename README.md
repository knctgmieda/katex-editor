# KaTeX エディタ for Notion

Notionのブロック数式入力を快適にするためのブラウザ用KaTeXエディタです．

## 機能

- **リアルタイムプレビュー** — 入力と同時に数式をレンダリング
- **シンタックスハイライト** — `\begin`・`\end`・コマンド・括弧などを色分け表示
- **MathTypeライクなパレット** — 9カテゴリのシンボルボタン
  - ギリシャ文字（小・大）
  - 演算子・関係
  - 分数・根号・上下付き
  - 積分・総和・極限
  - 括弧・デリミタ（自動サイズ）
  - 行列・構造（cases・aligned・連立方程式）
  - 矢印
  - 集合・論理・その他
- **自動補完**
  - `\\` と入力すると自動的に `\\[Xpt]` を挿入（行間デフォルト値は変更可能）
  - 括弧 `( )` `[ ]` を自動的に `\left( \right)` 等に変換（プレビュー時）
- **最近使ったボタン** — 直近5件のシンボルを入力欄の下に表示
- **検索・置換** — 式中の文字列を一括置換・削除（正規表現対応）
- **Undo / Redo** — `Ctrl+Z` / `Ctrl+Shift+Z`（または `Ctrl+Y`）
- **Notionブロック数式用コピー** — デリミタなしでKaTeXをコピー

## 使い方

1. パレットのボタンをクリック，または直接KaTeXを入力
2. プレビューでリアルタイム確認
3. **「コピー（Notionブロック数式用）」** をクリック
4. Notionで `/数式`（ブロック数式）を開いて貼り付け

## デフォルト入力

起動時・クリア時は以下の状態で始まります．

```
\begin{aligned}

\end{aligned}
```

## ショートカット

| キー | 動作 |
|---|---|
| `Ctrl+Z` | アンドゥ |
| `Ctrl+Shift+Z` / `Ctrl+Y` | リドゥ |
| `Tab` | インデント（スペース2つ）|

## 動作環境

インターネット接続が必要です（KaTeXをCDNから読み込みます）．

- Chrome / Edge / Firefox / Safari（モダンブラウザ全般）
- インストール不要，ローカルファイルまたはGitHub Pages上で動作
